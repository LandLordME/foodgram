Исходная коллекция Postman не изменена. В её проверке поиска используется
регистрозависимый `startsWith`, хотя задание требует поиск без учёта регистра.
`scripts/prepare_postman.py` исправляет ровно это сравнение в отдельной копии.
Собственный сценарный тест отдельно проверяет смешанный регистр кириллицы.

Во время проверки исправлен конфликт URL статики: `/static/` используется
интерфейсом React, `/backend_static/` — Django admin и DRF. Скрипт
`scripts/check_site.py` проверяет фактические JS/CSS-файлы из HTML, API и
админскую статику через nginx.

Контейнерный запуск использует PostgreSQL. Сценарные тесты и полная коллекция
Postman выше выполнены на отдельных локальных SQLite-базах. Workflow GitHub
Actions дополнительно выполняет их на PostgreSQL и проверяет Docker-стек.

Публикация образов Docker Hub и деплой на внешний сервер требуют настройки
аккаунта, адреса сервера и секретов CI/CD. Эти внешние этапы не считаются
выполненными только на основании наличия workflow-файла.
